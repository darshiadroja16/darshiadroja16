## 👋 About Me

I'm a final-year Computer Science student focused on building AI agents, retrieval-augmented generation (RAG) systems, and backend platforms. My projects span research automation, semantic resume matching, and computer-vision experiments.

---

## 🚀 Featured Projects

### [Multi-Agent Research Assistant](https://github.com/darshiadroja16/Multi_Agent_Research_Assistant)
Searches arXiv papers, retrieves relevant passages with ChromaDB, and generates structured research summaries through a LangGraph agent workflow with a self-critique loop. Uses Gemini embeddings and Groq-hosted Llama 3.3. [Live demo](https://multiagentresearchassistant-jyfbxsqksjvcyhgvar235w.streamlit.app/)

### [AI Resume Screener + ATS Score](https://github.com/darshiadroja16/Resume_Screener_ATS)
Ranks resumes against a job description using FastAPI, a React/Vite frontend, spaCy keyword extraction, Sentence-BERT embeddings, and FAISS similarity search.

### [MedXray Analyzer](https://github.com/darshiadroja16/MedXray_Analyzer)
Team medical-imaging project for chest X-ray analysis. My documented contribution is the YOLOv8 pneumonia bounding-box detection module; other analysis modules are owned by teammates.

### [Workspace Dashboard Chrome Extension](https://github.com/darshiadroja16/My_Dashboard_Extention)
Chrome Manifest V3 new-tab dashboard with draggable notes and task lists, reminders, and browser notifications, built with HTML, CSS, and JavaScript.

More projects: [Weather App](https://github.com/darshiadroja16/Weather-App) · [Task Manager](https://github.com/darshiadroja16/TASK-MANAGER)
